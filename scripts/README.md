# Scripts

Python scripts that download and process data.

- `fetch_core.py`: downloads hourly PTF (TRY, EUR, USD), SMF, system direction, real-time consumption and real-time generation by source. Cleans them and writes daily, monthly and recent-hourly files to `data/processed/`, plus a data quality report. Run `python scripts/fetch_core.py --help` for options.
- `price_limits.py`: reads `data/price_caps.csv` (the PTF price cap by period) and flags hours at the cap. Used by `fetch_core.py`.
- `probe_extra.py`: one-off probe. Downloads a few days from candidate EPİAŞ calls (congestion, wind forecast, reservoirs, interconnection lines, gas prices) and prints their columns. Run it before writing a real fetch for a new series.
- `fetch_extra.py`: downloads the extra EPİAŞ series month by month with a full backfill: gas spot (SGP) and balancing (BGP) prices, balancing instructions (bpm-up, bpm-down), wind generation and forecast, the TEİAŞ load plan, interconnection line outages and YEKDEM installed capacity (licensed and unlicensed), YEKDEM unlicensed generation, congestion cost by province, interconnection line capacities, and extra daily gas series (system direction and imbalance, spot matched quantity and value, physical entry and exit). It also saves one reservoir snapshot per run, because EPİAŞ publishes only the latest day. Writes daily and monthly files to `data/processed/` and `quality_report_extra.md`. Run `python scripts/fetch_extra.py --help` for options.
- `daily_digest.py`: builds the one-page overview of the latest day from `data/processed/` (HTML and text) and sends it by e-mail through SMTP when the mail secrets are set. Run by the `notify` job of the daily workflow.
- `update_data.py`: the daily update, run by `.github/workflows/update-data.yml`. Downloads only the last two months (plus one month of context) into a temporary folder, builds them with the code of `fetch_core.py` and `fetch_extra.py`, and swaps those days into the files in `data/processed/`; older rows are never touched. Takes a reservoir snapshot first. Checks the result, leaves a file as it was if a check fails, and writes `data/processed/update_status.json` (newest day per file, warnings, errors). `--deep` refreshes six months; `--target DIR` writes somewhere else for a trial.
- `probe_history.py`: one-off probe of how far back each call goes, plus congestion cost for full months and the interconnection capacity calls. Run it before writing the fetch for those series.
- `probe_login.py`: one-off check that a machine can log in to EPİAŞ and download a day of data (PTF, consumption, spot gas, reservoirs). Run by the manual workflow `.github/workflows/epias-login-test.yml`; prints the machine's public IP and never prints credentials.
- `gip_volatility.py`: rebuilds the GİP "perfect trader" volatility measure for a month of hourly contracts.

Scripts read credentials from environment variables (`EPTR_USERNAME`, `EPTR_PASSWORD`). In Colab, keep them in Secrets. In GitHub Actions, keep them in the repository's Settings, under Secrets and variables.
